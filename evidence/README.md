# Evidence

Judges can check every claim in the README here.

- `payments.md`: real payments with transaction links (generated by `pnpm evidence` from live errands).
- `guard-blocks.md`: blocked attempts with the rule and reason.
- `reppo.md`: every Reppo evaluation id, with averages by guard version.
- `screenshots/`: the app at 390 px and 1280 px; SERV console usage, Shadow Agent and Safety reports; the guard graph's Runs panel and heatmap; the Kite dashboard activity; the data-collection setting.
- `raw/` (gitignored): raw kpass and Reppo output from the spikes. Never commit it: it can contain session details.

Nothing here is filled in until it has really happened.
